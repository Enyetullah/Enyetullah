# 🔬 Research & Technical Experience

## 🧠 Vision-Based Exergame for Stroke Rehabilitation

**Repository:** [Exer-Game-for-Stroke-Rehabilitation](https://github.com/Enyetullah/Exer-Game-for-Stroke-Rehabilitaion)

Developed a low-cost, webcam-based upper-limb rehabilitation system using **Python, OpenCV, MediaPipe, and Pygame**.

- Implemented real-time hand and movement tracking
- Used One Euro filtering and rolling-median smoothing to reduce tracking jitter
- Designed deterministic/seeded exercises for repeatable experimental conditions
- Calculated quantitative progress, accuracy, endpoint error, and trial outcomes
- Logged structured spatiotemporal movement data to CSV for analysis
- Evaluated repeated rehabilitation sessions and movement performance

**Focus:** computer vision, healthcare technology, movement analysis, HCI, reproducible experimentation, real-time systems.

---

## 🔐 Multimodal Machine-Learning Prototype

**Repository:** [multimodal_biometric](https://github.com/Enyetullah/multimodal_biometric)  

Built a Flask-based prototype combining **facial information and behavioral typing signals** using machine learning and weighted decision-level fusion.

- Built OpenCV-based face processing and similarity scoring
- Modeled typing behavior using One-Class SVM
- Engineered keystroke and mouse-derived features
- Evaluated thresholds, FAR/FRR, and multimodal decision behavior
- Added step-up verification, logging, API testing, and automated validation

**Focus:** multimodal ML, behavioral modeling, computer vision, model evaluation, reliable decision systems.
