## 🤖 Multimodal Biometrics Prototype

**Repository:** [multimodal_biometric](https://github.com/Enyetullah/multimodal_biometric)

A Flask-based research prototype for multimodal authentication using simulated physiological input, behavioral biometrics, and facial scoring. The project explores decision-level fusion, One-Class SVM-based behavioral modeling, step-up OTP authentication, rough FAR/FRR evaluation, and authentication logging.

**Main areas:** AI security, behavioral biometrics, authentication, Flask, OpenCV, scikit-learn

**Demo:** [Watch on YouTube](https://youtu.be/6AVApKvunD0)

## 🧪 My AI Engineering Mindset

</div>

I believe strong AI work requires more than just using a model. A good AI system should be understandable, tested, useful, and connected to a real problem.

When I build AI-related projects, I try to ask:

- What problem does this solve?
- What data or signals are being used?
- What features matter?
- What method is appropriate?
- How is performance measured?
- What are the limitations?
- How can the system be improved?
